# Catálogo de skins

Todas tienen modelo desde el lote 6, aunque **ninguna se vio todavía en Studio**.
- Las 25 nuevas están en `ReplicatedStorage/SkinDesigns.lua`: diseños por código con hojas curvas, púas, arcos, brillo y partículas.
- Las 7 de Codex están en `Skins.Designs`, dentro de `Skins.lua`.
- Para verlas todas juntas: pega `tools/preview_skins.lua` en la barra de comandos de Studio. Cada una muestra su número de piezas.
- Si un diseño falla, el arma sale con el modelo base y la Salida muestra «[WeaponBuilder] Falló el diseño…».

Imágenes: `F:\RobloxJuegos\skins armas\<carpeta>\`.
